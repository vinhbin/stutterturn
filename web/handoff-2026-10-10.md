## UI compatibility correction

The server discovers `file: "benchmark/audio/HeStutters_4_32.wav"`; the previous
adapter rejected every slash and therefore failed before opening its WebSocket.
The adapter now accepts safe relative paths while retaining discovered-source
membership and acknowledgement identity checks. It sends the exact discovered
path. Absolute paths, drive/URI forms, traversal, empty segments, backslashes,
control characters and encoded ambiguity remain rejected.

The actual server response shape was reproduced as a failing regression before
the fix. All 53 adapter checks pass, including the original 29 and 24 added path
and identity cases. Test tooling remains in local scratch, as in the original
builder handoff.

## Remaining producer questions

- **Audio output:** `engine.py` receives/counts TTS PCM and emits markers but
  discards the samples. No source player, response player or browser audio stream
  exists. The contract's “scheduled to play” wording exceeds the implementation.
  The UI keeps **backend-reported / playback unverified** labels. Guttuu owns
  implementing and verifying the audible path.
- **Candidate in dry mode:** `.env` is loaded only by `Services.__init__`.
  With `--services off`, a `CANDIDATE_MODEL` entry in that file is not loaded;
  the variable would need to exist in the process environment. Guttuu/Niko should
  align setup instructions and candidate acceptance before enabling that arm.
- **Decision measurement:** the model decision uses a source-frame timestamp
  captured before awaited inference. It does not measure inference completion
  time. Preserve reported values, and clarify the clock before latency claims.
- **Human validation:** source excerpts and inferred gaps do not establish true
  turn ends. Human labels and matched completed-turn evaluation remain separate.

These findings are recorded for the user; no messages were sent to teammates and
no producer files were edited. Model-only UI integration cannot close the audible
interaction or model-efficacy gates.

no audible interruption in any of the 10 runs. The review above is kept as
written for the record; cite replay v2, not the first replay, for current
numbers. Labels remain exploratory and energy-derived; five clips support no
rates.
