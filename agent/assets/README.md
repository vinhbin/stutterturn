# Fixed-response audio

`fixed-reply.wav` says: "What would you like help with?"

Generated offline on October 11, 2026 using Windows System.Speech, Microsoft
David Desktop at its default rate, mono 16 kHz PCM16. Duration: 2.24 seconds.
This is synthetic assistant speech, not a recording of a person who stutters,
not a voice clone, and not an ElevenLabs/Gemini output.

The controlled comparison uses the identical WAV and a one-second simulated
reply delay for every model configuration. Cancellation is unchanged. No
provider calls occur in this mode. The mode, delay, duration and audio SHA-256
are recorded in health, run metadata and summaries. This does not measure
live API latency or establish a general interruption reduction.
