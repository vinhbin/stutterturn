The claim we’re testing

Can a more patient turn policy avoid answering during a speaker’s pause, while still responding promptly when the turn is finished?

The current replay examines early decisions. It does not yet establish better interruption rates or completed-turn response delay.

How to evaluate it

Use the live workspace for runs. Use the recorded artifacts to check what the evidence supports.

Open live workspace
  1. 01

    Keep the recording fixed

    Connect a replay backend in the workspace and choose a source. Keep the same source for both configurations. These are recorded inputs; this path does not capture a live microphone or phone call.

  2. 02

    Run stock, then start fresh with patient

    Inspect stock’s run record, then choose patient and start a fresh run. The silence gate changes from 0.2 s to 1.0 s; the underlying turn model stays the same. A trained candidate was not evaluated in this replay.

  3. 03

    Separate a decision from a response

    Find the turn-complete decision, any resumed caller speech, and the first reported agent audio. A reply can be cancelled after the decision and before audio receipt. The console’s event record keeps these moments separate.

  4. 04

    Check the artifacts and the limits

    Match the run’s source, configuration, and model metadata to the logs. Treat mock or development preview events as synthetic. The recorded replay uses three-second excerpts followed by five seconds of synthetic silence; those clips cannot establish completed-turn response delay.

Follow the path through the system

Recorded-input replay

  1. Audio input

    A SEP-28k recording enters the replay path.

  2. VAD + turn model

    Speech detection locates activity. The model checks whether the turn is complete.

  3. Hold or reply

    The policy waits or requests a response. Resumed speech can cancel that request.

  4. Gemini → ElevenLabs

    Response generation and speech synthesis lead to reported audio receipt.

Speaker playback remains pending verification. The workspace visualizes events and does not play audio. Inspect the replay event contract and the implementation used for the saved runs.
